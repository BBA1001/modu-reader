# 墨读 Modu Reader

一款**低干扰、零跳转**的逐段阅读辅助工具，专为注意力敏感、阅读困难人群设计。
把长文拆成小段，配合划词极简解释，让你不用跳出阅读、不用切APP，就能顺畅地读完一整段文字。

> 核心理念：我们拼的不是「AI解释得有多全」，而是「打断阅读的成本有多低」。

## ✨ 核心特性
- 📖 **逐段拆分阅读**：自动把长文本拆成舒适的小段，降低阅读心理负担
- 💡 **划词极简解释**：选中文字一键解释，结果直接显示在段落内，视线不离开正文
- 🎯 **AI辅助精读**：自动提取核心锚点、生成理解测试，强化阅读记忆
- 🧘 **沉浸模式**：隐藏所有按钮菜单，只剩文字，最大限度减少干扰
- 💾 **本地进度保存**：阅读进度自动存在浏览器，刷新不丢失
- 📦 **单文件部署**：纯PHP实现，零依赖，上传到虚拟主机/宝塔就能用
- 🔒 **数据完全自控**：支持自托管，自行配置API Key，所有数据在自己服务器

## 🚀 快速部署

### 环境要求
- PHP 7.4 及以上（推荐 8.0+）
- 开启 `curl`、`mbstring` 扩展（宝塔默认已开启）
- 至少一个大模型API Key（DeepSeek / 智谱AI）

### 部署步骤
1. 下载本仓库所有文件，上传到网站目录的 `modu/` 文件夹下
2. 访问 `你的域名/modu/admin.php` 完成初始化
3. 首次登录密码在 `modu_data/install_password.txt` 中，登录后请立即修改
4. 在PHP环境变量中配置你的API密钥：
   ```ini
   env[DEEPSEEK_KEY] = 你的DeepSeek Key
   env[ZHIPU_KEY] = 你的智谱Key
（宝塔面板：软件商店 → PHP设置 → FPM配置文件[www]末尾添加后重启PHP）
5. 访问  你的域名/modu/  即可开始使用

### 目录结构
- `modu/` 程序文件目录
  - `index.html` 主阅读器页面
  - `modu_ai.php` AI 接口核心文件
  - `admin.php` 管理后台
- `modu_data/` 运行时数据目录（系统自动创建，权限 0700）
- `modu_log/` 运行时日志目录（系统自动创建）

📖 使用说明
 
- 在输入框粘贴你要读的文字
- 点击「开始阅读」，文字会被拆成小段
- 读完一段点击「已理解·继续」进入下一段
- 选中段落内的文字，点击「解释选中内容」查看极简释义
- 按  **I**  键切换沉浸模式，按  **空格**  快速翻段
 
🎯 设计原则
 
本项目有明确的功能边界，所有开发和PR都将遵循以下原则：
 
✅ 我们做的
 
- 降低阅读的干扰，帮用户专注地读下去
​
- 用最小的信息解决阅读卡点，不打断阅读节奏
​
- 保持轻量、单文件、易部署的特性
 
❌ 我们不做的
 
- 不做电子书上传、书库管理、格式解析
​
- 不做联网搜索、扩展背景知识、多轮对话
​
- 不做笔记、摘抄、导出等阅读器通用功能
​
- 不和通用大模型比解释深度、比知识面
 
如果你想要更全的功能，微信读书、豆包、各类阅读器都做得更好；我们只做好「最低干扰的阅读辅助」这一件事。
